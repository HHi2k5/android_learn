## App theo dõi lộ trình

Cần Node.js. Chạy rồi mở http://127.0.0.1:4321

```bash
node tracker/server.js
```

- Tick mục nào thì app ghi thẳng `[x]` vào `LO_TRINH.md`.
- Ngày bắt đầu, giờ học, nhật ký tuần lưu ở `tracker/data.json` (commit cùng repo để giữ tiến độ).
